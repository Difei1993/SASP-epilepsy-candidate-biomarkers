# Original analysis scripts

This folder is reserved for the original analysis scripts supplied by the authors before synchronization with the final revised manuscript.

The final manuscript replaces the earlier GSE134697 cross-region analysis with the cortical validation dataset GSE190451 and retains four replicated candidate biomarkers (SERPINE1, IGFBP4, C3, and SPX). Therefore, legacy scripts that still reference GSE134697 or the original five-gene panel should not be interpreted as the final submitted analysis workflow.
