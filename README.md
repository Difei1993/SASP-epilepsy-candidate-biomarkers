# SASP-related candidate biomarkers in epilepsy

This repository contains analysis scripts supporting the manuscript:

**Identification and preliminary validation of senescence-associated secretory phenotype-related candidate biomarkers in epilepsy**

## Public transcriptomic datasets

- GSE256068 — discovery cohort
- GSE190451 — independent cortical validation dataset used in the revised manuscript

## Repository status

The repository is currently being synchronized with the final revised manuscript.  
The final public release will include the analysis scripts corresponding to the submitted revision, together with software/package information and a reproducible run order.

**Do not cite this repository as the final analysis release until the version tag `v1.0.0` is available.**
